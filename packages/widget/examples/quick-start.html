FiberTap Quick Start

Add CKB micropayments to any website in under 60 seconds. One script tag. No accounts.

1 Add the Widget

Paste this before </body> on your website. Replace the address with your CKB address.

<!-- FiberTap Tip Widget --> <script src="https://cdn.fibertap.dev/widget.min.js" data-creator="YOUR_CKB_ADDRESS_HERE" ></script>

That's it! The widget renders automatically with default settings.

2 Customize (Optional)

Add data-* attributes to change appearance and behavior:

data-theme="dark"light, dark, or auto
data-position="bottom-left"bottom-right (default)
data-preset="1,5,10,25"Quick-select amounts (CKB)
data-label="Support"Button tooltip text
data-mode="qr"wallet (default) or qr
data-api="https://api.fibertap.dev"API endpoint

Full example:

<script src="https://cdn.fibertap.dev/widget.min.js" data-creator="ckt1qyq..." data-theme="auto" data-position="bottom-right" data-preset="1,5,10,25" data-label="Buy me a coffee" data-mode="wallet" ></script>

3 Register as a Creator (For Webhooks)

Optional — register to receive webhook notifications when payments are confirmed:

# Register your CKB address curl -X POST https://api.fibertap.dev/api/creators/register \ -H "Content-Type: application/json" \ -d '{"ckbAddress": "YOUR_CKB_ADDRESS", "displayName": "Your Name"}' # Response: { "id": "...", "apiKey": "ft_live_..." } # Set up a webhook (auto-generated secret returned) curl -X POST https://api.fibertap.dev/api/creators/YOUR_ID/webhooks \ -H "Content-Type: application/json" \ -H "x-api-key: ft_live_YOUR_KEY" \ -d '{"url": "https://yoursite.com/webhook-handler"}' # Response: { "webhookId": "...", "secret": "whsec_..." }

4 Platform-Specific Guides

WordPress Add the script tag to Appearance → Theme Editor → footer.php, or use a "Custom HTML" widget in the sidebar.
Ghost / Substack Go to Settings → Code injection → Site footer. Paste the script tag there.
GitHub Pages / Static Sites Add before </body> in your HTML template or layout file.
Twitter / X Bio Link to a page on your site that has the widget. The widget works on any webpage.
Discord Bot Register for webhooks, then listen for payment.confirmed events to announce tips in a channel.
Next.js / React Use next/script with strategy="lazyOnload" or add to _document.tsx.

API Reference

Endpoint Method Description
/api/creators/register POST Register a creator account. Returns id and apiKey.
/api/creators/:id GET Get creator profile and widget config.
/api/creators/:id/config PATCH Update widget theme, presets, label. Requires API key.
/api/creators/:id/webhooks POST Register a webhook URL. Server generates secret. Requires API key.
/api/creators/:id/webhooks/:whId DEL Delete a webhook. Requires API key.
/api/payments/request POST Create a payment request. Public endpoint (called by widget).
/api/payments/:id/confirm POST Confirm a payment with txHash. Public endpoint (called by widget).
/api/payments/:id/status GET Check payment status (pending/confirmed/failed).
/health GET Health check. Returns server status and network.
